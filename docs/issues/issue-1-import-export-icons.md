# Issue #1: インポート・エクスポートアイコンの修正

## 概要

[GitHub Issue #1](https://github.com/sifue/zen-course-planner/issues/1) の報告どおり、
ヘッダーのインポートとエクスポートに表示していた矢印アイコンの向きが、
一般的な操作イメージと逆になっていた。

## 修正内容

- エクスポート: 外向き矢印の `Upload` アイコン
- インポート: 内向き矢印の `Download` アイコン

ボタンの表示文言、アクセシビリティラベル、クリック時の処理は変更していない。
エクスポートモーダル内の「ダウンロード」操作は実際のファイル保存を示すため、
引き続き `Download` アイコンを使用する。

## 確認項目

- ヘッダーの「エクスポート」に外向き矢印が表示される
- ヘッダーの「インポート」に内向き矢印が表示される
- 両ボタンのクリック処理が入れ替わっていない
- TypeScriptの型チェックと本番ビルドが成功する
